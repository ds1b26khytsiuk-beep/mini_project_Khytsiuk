## Дослідницьке питання
Як рівень заробітної плати Junior-фахівців з даних залежить від технологічного стеку та місця роботи?

## Джерело даних
* **Набір даних:** Результати зарплатних опитувань розробників та фахівців з даних.
* **Постачальник даних:** Портал DOU (відкриті дані).

## Структура репозиторію

```text
mini-project-khytsiuk/
├── data_raw/           # сирі дані без змін (початкові таблиці Excel)
├── data_clean/         # очищені дані та розрахунки
├── presentation/       # презентація з графіками та висновками
└── README.md           # опис проєкту
```

| Директорія / Файл | Опис вмісту |
| :--- | :--- |
| `data_raw/` | Початкові файли Excel до проведення очистки даних |
| `data_clean/` | Очищені таблиці Excel із проведеними розрахунками |
| `presentation/` | Фінальна презентація PowerPoint з графіками та висновками |
| `README.md` | Головний файл опису мініпроєкту |

## Виконані дії
1. Зібрано та завантажено початкові таблиці з результатами опитування (`data_raw`).
2. Проведено очистку даних: видалено пропуски, дублікати та неактуальні записи (`data_clean`).
3. Виконано групування та статистичні розрахунки медіанних і середніх зарплат за стеком та регіонами.
4. Побудовано візуалізації та оформлено висновки у вигляді презентації (`presentation`).

## Отримані результати
* Підтверджено залежність рівня заробітної плати Junior-фахівців від обраного технологічного стеку та локації / формату роботи.

## Використані засоби
Microsoft Excel, Microsoft PowerPoint, Visual Studio Code, GitHub.
