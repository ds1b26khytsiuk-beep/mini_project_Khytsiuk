#  Аналіз зарплат Junior-фахівців з даних

**Автор:** Уляна Хицюк  
**Дослідницьке питання:**  Як рівень заробітньої плати Junior-фахівців з даних залежить від технологічного стеку та місця роботи? 
**Джерело даних:** Відкриті дані зарплатних опитувань
## Структура репозиторію

```text
mini-project-khytsiuk/
├── data_raw/           # початкові таблиці Excel без очистки
├── data_clean/         # очищені та оброблені таблиці Excel
├── presentation/       # фінальна презентація PowerPoint
└── README.md           # опис дослідження та структури проєкту
```

| Директорія / Файл | Опис вмісту |
| :--- | :--- |
| `data_raw/` | Початкові (сирі) файли Excel до проведення очистки даних |
| `data_clean/` | Очищені Excel-таблиці з проведеними розрахунками |
| `presentation/` | Презентація PowerPoint з графіками та основними висновками |
| `README.md` | Головний файл опису мініпроєкту |
